# FolkSound Atlas

> 世界の民謡を、音の構造から眺めるデジタル・アトラス。

権利を一件ずつ確かめた民謡の録音を、波形・スペクトログラム・従来型音響特徴量・
深層学習 Embedding の順に並べ直し、**地理**と**音響**という二つの空間を並べて見比べる。

中心にある問いはひとつ。

> **地理的に近い音楽は、音響的にも近いのか。**

この地図帳は、その問いに「はい」と答えるために作られていない。
**測って、答えが何であれ画面に出す**ために作られている。

---

## 設計上の要点

### 循環を禁じる

もとの仕様は、自作 CNN を**地域分類器**として学習させたうえで、
「音響空間のクラスタは地理的境界と一致するか」を問うことになっていた。
この二つを同時に採ると**循環する** —— 国名を教わった Embedding が国ごとに固まるのは、
発見ではなく構成上の必然である。

そこで Embedding を「国ラベルを見たか」で二分し、
**地理の主張に使ってよいのはラベル非依存の系だけ**とした(SPEC §2.2 / §8、ゲート G-04)。

| 系統 | 国ラベル | 地理の主張 |
|---|---|---|
| 従来型音響特徴量(librosa) | 見ていない | ✓ |
| 自作 CNN(自己教師あり・再構成) | 見ていない | ✓ |
| 事前学習済みモデル | 見ていない | ✓ |
| 自作 CNN(国分類器) | **見た** | **✗(対照としてのみ表示)** |

国分類器はアプリから消さない。**「答えを教わった側」として並べて見せる**ことが、
循環とは何かを示すいちばん分かりやすい方法だからである。

### 目玉を先に登録し、外れたら外れたと書く

- **H-01(目玉)** 地理距離と音響距離に正の相関がある(Mantel 置換検定・両側 p<0.05)
- **H-02(対照)** その相関は**録音の出自**(収録年代・帯域・アップロード元)で説明されない

歴史的録音の寄せ集めでは、CNN が真っ先に拾うのは楽曲構造ではなく**録音機材と帯域**である。
H-02 を置かずに H-01 だけを主張してはならない。

### 測った答え —— 目玉は立たなかった(2026-09-08)

録音 314 本 / 37 国 / 投稿者 122 人、置換 999 回・乱数種 42。

| | 従来型特徴量 | 自作 CNN(自己教師あり) |
|---|---:|---:|
| 地理 × 音響(H-01) | r=+0.039(p=0.0010) | r=+0.035(p=0.2050) |
| 出自を統制(H-02) | r=−0.004(p=0.4650) | r=+0.009(p=0.7850) |
| **出自 × 音響(対抗)** | **r=+0.206(p=0.0010)** | r=+0.126(p=0.0010) |

地理との相関は有意でも **r=0.039 と極めて小さい**。有意なのは対の数が多い
(314 本 = 49,141 対)からであって、効果が大きいからではない。
しかもその相関は**録音の出自を統制すると消える**。
いっぽう出自そのものは音響距離を **5 倍強く**説明する。

つまりこのコーパスで音響的な近さが主に語っているのは
**「誰が、どの機材で、どのバッチでデジタル化したか」**であって、地理ではない。
候補 5,492 件の 88% が Wikimedia Sverige の 2 アカウントによる一括投稿で、
国ごとに上限 20 件を課して均してもなお残った。**均すことでは交絡は消えない。**

この結果はアプリの画面に出している。ホームの見出し文は `analysis.json` の判定から
選んでおり、**都合のよい結果が出たときだけ書く、という経路が無い**。

## 採らなかったデータ源(実測 2026-09-07)

もとの仕様が最優先に据えていた **Library of Congress は採っていない。**
`www.loc.gov` は対話型チャレンジの内側にあり、`robots.txt` すら機械には返らず、
JSON API(`?fo=json`)は **403** を返す。

Commons の **`deepcat:` 検索も使っていない。**
`deepcat:"Folk music of Ireland" filemime:audio` は `totalhits=112` を返すが、
上位の実体はスウェーデンの音源で、そのファイルのカテゴリを直接引くと
**アイルランド系カテゴリに一切属していない**。警告もエラーも出ない。
実際に `list=categorymembers` で数え直すとアイルランドは 23 件だった。
**もっともらしい件数を返す誤りは、件数を数えるだけでは捕まらない。**
地理帰属は明示的なカテゴリ所属からのみ取る(HC-226)。

## 構成

```
folksound-atlas/
├── src/                 Next.js(静的書き出しのみ・サーバ関数 0・cron 0)
├── ml/
│   ├── src/folksound/   特徴量・権利判定・モデル
│   ├── scripts/         ETL(01_discover → 08_export)
│   └── tests/           pytest
├── data/                取得物と中間生成物(音源は commit しない)
├── schemas/             配布 JSON の JSON Schema
├── logs/loops/          構造化ループログ
└── harness/             looplog / text_hygiene 等
```

```bash
# Python(**本プロジェクト専用の .venv を使う**。この機はシェルの VIRTUAL_ENV が

npm run typecheck
npm run build      # output: "export" → out/
```
